# Overseer

### Rebuild Branch

This branch is dedicated to a full function rebuild of the Overseer project.  
Such a rebuild is needed to allow for future features and modular functionality,  
working with a clean slate creates an opportunity to make this project into that  
which its original idea envisioned.  
---
This should bring some level of actual usability to the project, allowing for easy
installation and updates while creating a platform to support actually useful functionality  
for the project. Making it a less novel side piece.
